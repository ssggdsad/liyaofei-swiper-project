# Swiper 大国重器光影展

高级网页设计课堂项目：四个基础轮播任务、七种 effect（含 creative）、第六件爱达·魔都号展品和键盘控制。

## 打开方式

- 双击 `index.html`，自动进入综合作业 `swiper-task.html`。
- 保持 `swiper-imgs/` 和 `vendor/` 与页面同级；Swiper 11.0.3 和图片使用本地文件，无需联网加载组件库。

## 页面入口

- `swiper-task.html`：四个课堂任务，任务四初始 `slide`，点击按钮会销毁并重建实例。
- `prompt-cube-preview.html`：单独验证任务一的 cube 配置。它与任务四的 slide 默认要求分别演示。
- `prompts.html`：网页可访问的提示词、答辩问答与任务记录入口。
- `ai-dialogue.md`：完整 AI 对话记录文本。

## 验收摘要

- 任务一：最小拖动轮播；Cube 验证页循环、3200ms 自动播放、交互后续播、圆点可点击。
- 任务二：循环、600ms 动画、可点击分页和导航箭头。
- 任务三：循环、2600ms 自动播放、拖动后续播、分页器。
- 任务四：slide 默认、800ms 动画、3200ms 自动播放；6 个原效果加 creative 均可切换。
- 加分项：6 件展品；键盘左右键控制视口内的演示四。
